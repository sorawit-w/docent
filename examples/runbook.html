Restore a deleted project from the nightly backup

A workspace admin deleted a project in Example Planner and wants it back. This runbook brings the project back from the nightly backup in five steps, without touching the rest of the workspace. It takes about 20 minutes.

Runbook
  • About 20 minutes
  • Updated 27 November 2026
  • Owner: support engineering
  • Every name and command is invented

What you need

Example Planner keeps a backup of every workspace each night, for 30 days. A restore copies one project from that backup into a side database first. Nothing reaches the live workspace until you have compared the copy with what the admin expects.

Tick each line before you start. If one line is not true, stop and answer the ticket with what is missing.

Note A project deleted more than 30 days ago is gone. Say so on the ticket; do not open an incident for it.

Before you start

Restore the project

Follow the dot. Each step names one arrow in the figure: you act on the left, and the systems act on the right.

  1. Find the right backup.

    Look up the last backup made before the deletion time in the audit log. Write its date on the ticket.

  2. Restore it to a side database.

    Start the restore with --target side. It copies the one project and leaves the live workspace alone.

  3. Compare the copy.

    Open the copy in the console. The number of tasks and the latest due date should match what the admin wrote.

  4. Publish the copy.

    Publish the copy to the live workspace. The project comes back with its tasks, comments and files.

  5. Tell the admin.

    Answer the ticket with the backup date, so the admin knows which changes are not in it.

The commands

Run these from the admin console's shell. Replace the workspace and project names with the ones on the ticket.

List the backups

The list shows the newest backup first. Pick the last one made before the deletion time.

planner-admin backup list --workspace acme-design

Restore to the side database

The restore takes one to five minutes, by the size of the project. It prints the address of the copy when it is done.

# The date is the backup you picked; the project is its name on the ticket
planner-admin restore --workspace acme-design --project "Spring launch" \
  --backup 2026-11-25 --target side

Publish the copy

Publish only after your check. The command asks you to type the project name again.

planner-admin restore publish --workspace acme-design --project "Spring launch"

Note
