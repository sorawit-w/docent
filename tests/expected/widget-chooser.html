How you install

Installer

Run this in the project folder. It needs version 3 or newer.

app install
app test

From source

Use make when the folder has a Makefile.

make install

A second command runs the tests.

make test

By hand

  1. Download the archive.
  2. Unpack it into vendor/.
  3. Check that 2 < 3 & the folder exists.
  • No lock file is written.
  • Updates are not automatic.
